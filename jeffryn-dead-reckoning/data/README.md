# Data Directory

This directory contains sensor data files for the Dead Reckoning engine.

## `sample_sensor_data.csv`

Generated by `scripts/generate_test_fixture.py`. This is a **deterministic
90-second synthetic dataset** used for development and testing only.

It is **not** the final team sensor dataset from Arsheen.

### Columns

| Column                   | Type   | Unit    | Description                           |
|--------------------------|--------|---------|---------------------------------------|
| `timestamp`              | float  | seconds | Monotonically increasing time         |
| `gps_latitude`           | float  | degrees | GPS latitude (ground truth during OFF)|
| `gps_longitude`          | float  | degrees | GPS longitude                         |
| `speed_mps`              | float  | m/s     | Vehicle speed sensor reading          |
| `accel_x`                | float  | m/s²    | Forward acceleration (with noise)     |
| `accel_y`                | float  | m/s²    | Lateral acceleration                  |
| `accel_z`                | float  | m/s²    | Vertical acceleration (~9.81 m/s²)    |
| `gyro_x`                 | float  | deg/s   | Roll rate                             |
| `gyro_y`                 | float  | deg/s   | Pitch rate                            |
| `gyro_z`                 | float  | deg/s   | Yaw rate (used for heading)           |
| `gnss_available`         | string | —       | `ON` or `OFF`                         |
| `ground_truth_latitude`  | float  | degrees | True position (for evaluation only)   |
| `ground_truth_longitude` | float  | degrees | True position (for evaluation only)   |

### Journey Profile

```
 0–10 s   Stationary, GNSS ON
10–30 s   Accelerate North, GNSS ON
30–60 s   GNSS OFF (straight then right turn)
60–75 s   GNSS ON
75–90 s   Braking to stop, GNSS ON
```

### Replacing with Real Data

When Arsheen's official sensor CSV is ready, place it in this directory
and update the `--input` argument:

```bash
python dead_reckoning.py --input data/arsheen_sensor_data.csv
```

The engine will work with any CSV that has the required columns.
